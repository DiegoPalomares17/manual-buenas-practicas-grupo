## 🚀 Instrucciones de Uso y Contribución

### 1. Clonar el Repositorio
```bash
git clone [https://github.com/DiegoPalomares17/manual-buenas-practicas-grupo.git](https://github.com/DiegoPalomares17/manual-buenas-practicas-grupo.git)
cd manual-buenas-practicas-grupo
```
### 2. Flujo de Trabajo para Nuevas Contribuciones
1. **Crear una rama a partir de `main`:**
```bash
   git checkout -b feature/nombre-tarea
```

2. **Realizar los cambios y hacer commits atómicos:**

```bash
   git commit -m "Docs: Descripción del cambio"
```

3. **Subir la rama a GitHub:**
```bash
   git push origin feature/nombre-tarea
```

4. **Abrir un Pull Request (PR) hacia main y solicitar la revisión (Peer Review) de un compañero antes de fusionar.**

### 3. Consultar la Versión Final en PDF
El manual compilado se encuentra disponible en formato PDF listo para su descarga en la sección de Releases / Etiquetas (v1.0.0) del repositorio.
